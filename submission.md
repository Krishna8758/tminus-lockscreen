## Description  (replaces the current one)
A live countdown you can set to any deadline — it builds the plan backward for you. Four checkpoints across the run, the last holding a day of buffer, each flipping done / next / ahead on its own. Mine was Nov 23, 11:59pm PT. The lock screen is a blueprint: T-21 readable at arm's length, short milestones in order beneath it, top and bottom left empty so the clock, camera and torch cover nothing. One HTML file, so the number is never stale.
